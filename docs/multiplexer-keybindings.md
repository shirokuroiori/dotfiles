# wezterm + smart-splits.nvim マルチプレクサ操作

nvim のウィンドウと wezterm のペインを同じキーで横断操作するためのチートシート。
設定本体は `.config/wezterm/keys.lua` / `.config/wezterm/wezterm.lua` /
`.config/nvim/lua/plugins/smart-splits.lua` を参照。

## シームレス移動・リサイズ（smart-splits.nvim 経由）

nvim ウィンドウと wezterm ペインの境界を意識せず移動・リサイズできる。
端に到達すると自動的に隣の wezterm ペインへ移譲される。

| キー       | 動作                                  |
|------------|---------------------------------------|
| `Ctrl+h`   | 左へ移動（nvim ↔ wezterm ペイン）     |
| `Ctrl+j`   | 下へ移動                              |
| `Ctrl+k`   | 上へ移動                              |
| `Ctrl+l`   | 右へ移動                              |
| `Alt+h`    | 左方向にリサイズ                      |
| `Alt+j`    | 下方向にリサイズ                      |
| `Alt+k`    | 上方向にリサイズ                      |
| `Alt+l`    | 右方向にリサイズ                      |

## wezterm ペイン操作

| キー                 | 動作                                       |
|----------------------|--------------------------------------------|
| `Ctrl+Shift+\`       | 横方向に分割（左右に並べる）                |
| `Ctrl+Shift+-`       | 縦方向に分割（上下に並べる）                |
| `Ctrl+Shift+w`       | 現在ペインを閉じる（確認あり）              |
| `Ctrl+Shift+z`       | ズームトグル（全画面 ↔ 分割）              |
| `Ctrl+Shift+r`       | ペイン並び替え（時計回り）                  |
| `Ctrl+Alt+Shift+r`   | ペイン並び替え（反時計回り）                |
| `Ctrl+Shift+s`       | 番号オーバーレイで選んだペインとスワップ    |
| `Ctrl+Shift+p`       | 番号オーバーレイで選んだペインにフォーカスをワープ |

## nvim 内のリサイズモード

| キー         | 動作                                |
|--------------|-------------------------------------|
| `<leader>wr` | smart-splits のリサイズモードに突入  |

## 用語整理

| 用語                  | 指す対象                                                       |
|-----------------------|---------------------------------------------------------------|
| wezterm のペイン      | wezterm が画面を分割した1区画。1つにつき1プロセス（shell, nvim 等） |
| nvim のウィンドウ     | nvim 内部の分割（`:split` `:vsplit` で作る）                   |
| nvim のバッファ       | ファイルの中身。window はバッファを表示する枠                   |
